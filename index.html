BRAWL ARENA

Survis aux vagues de robots. Stick gauche : bouger. Stick droit : viser (sinon le tir est automatique). Clavier : WASD + souris, Espace = Super, E = auto-tir. Cache-toi dans les buissons et ramasse les kebabs pour te soigner ! Manette Xbox : stick gauche = bouger, stick droit = viser, RT = tirer, A = Super, B ou RB = Dash, X = auto-tir, Start = pause ou jouer.
